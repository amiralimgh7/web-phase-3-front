# Web Frontend Scaffold

An incomplete React project snapshot. The repository contains package manifests and public assets, but the `my-app/src/` application source is missing. The configured start, build, and test scripts therefore need the missing source before they can be used.

For the implemented quiz frontend, see [Phase 3](https://github.com/amiralimgh7/Web_Fall1403_Phase3_FE) or [Phase 4](https://github.com/amiralimgh7/Web_Fall1403_Phase4_FE).

## Contents

| Path | Purpose |
| --- | --- |
| `my-app/package.json` | React application dependencies and scripts |
| `my-app/package-lock.json` | Application dependency lockfile |
| `my-app/public/` | Public assets |
| `package.json`, `package-lock.json` | Root dependency snapshot |

Dependency folders are generated by npm and excluded from version control. This repository is retained as a scaffold rather than presented as a complete application.
